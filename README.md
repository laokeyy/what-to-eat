# 🎲 这顿吃什么

**用排除法帮你决定外卖，告别选择困难症**

[在线体验](https://what-to-eat-one-lyart.vercel.app) · [GitHub Pages](https://laokeyy.github.io/what-to-eat/)

</div>

---

## ✨ 核心功能

### 🧠 智能排除式问答
通过 5 个问题逐步排除不想要的，30+ 题库随机组合，每次不一样

### 🎰 老虎机抽选动画
酷炫滚动动画随机抽出最终结果

### 📋 食谱管理
自定义添加爱吃的外卖，冷冻/解冻管理

### 🚫 黑白名单
拉黑踩雷的店，收藏常吃店，记录原因

### 📐 规则引擎
自定义规则：不吃辣、工作日不火锅、预算限制等

### 🩺 健康模式
正常/健康/放纵三种模式切换

### 🌤️ 天气感知
根据天气推荐：下雨推热汤，大热天推冷食

### 📱 响应式
桌面侧边栏 + 移动端汉堡菜单，深色主题
