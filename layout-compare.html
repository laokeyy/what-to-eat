🍜 「这顿吃什么」— 整体布局方案对比

16个功能如何组织？哪种导航结构更适合？点击卡片选中你倾向的方案

A

单页滚动流

所有功能一个长页面，打开即进入问答流程。底部Tab切管理页。类似抖音沉浸感。

✅ 优点

  • 打开即用，零学习
  • 沉浸式体验
  • 移动端友好

❌ 缺点

  • 功能多时拥挤
  • 桌面端利用率低
B

底部5Tab导航

🎲选饭吃 / 📋食谱 / ⚙️规则 / 👤我的 / 🔮发现。移动端优先，类似美团结构。

✅ 优点

  • 功能分区清晰
  • 用户心智模型熟悉
  • 每Tab独立状态

❌ 缺点

  • 非主Tab打开率低
  • 切Tab打断上下文
C

侧边栏 + 主内容区

左侧垂直导航栏，右侧大内容区。桌面端优先，响应式适配移动端。

✅ 优点

  • 桌面端体验最佳
  • 导航不占主区域
  • 扩展性强

❌ 缺点

  • 移动端需额外适配
  • 初版开发量大
⭐ 推荐
D

混合方案：全屏主流程 + 抽屉菜单

核心"选饭吃"全屏沉浸式。左上角汉堡菜单打开Drawer访问其他功能。桌面端Drawer常驻为侧边栏。

✅ 优点

  • 主流程不被干扰
  • 桌面/移动端自然适配
  • 功能可达性好

❌ 缺点

  • 功能发现性略低
  • 抽屉层级需注意
